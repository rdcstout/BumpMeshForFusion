# Changelog

## 0.1.1 - 2026-09-03

- Size the docked BumpMesh palette to 48 percent of Fusion's current modeling
  viewport on macOS and Windows instead of using fixed screen dimensions.

## 0.1.0 - 2026-09-03

- Add the BumpMesh command to Fusion's Solid workspace.
- Export a temporary copy of the selected solid body without changing the
  editable Fusion model.
- Open the bundled BumpMesh interface docked inside the right side of Fusion.
- Allow face selection in BumpMesh before applying texture.
- Save finished STL and 3MF files through Fusion's native save dialog.
- Add macOS and Windows installer packaging.
